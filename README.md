# GBbooking.com Platform

Mobile-first local-services marketplace frontend for Gilgit-Baltistan, built with React and Vite.

## Run locally
1. Install Node.js LTS.
2. Run npm install.
3. Run npm run dev.
4. Run npm run build for production assets.

## Scope
Responsive service discovery, sample listings, category and location filters, saved cards, and a managed booking-request interface. Booking requests are demo-only until Supabase is connected.

## Next stages
Connect Supabase Auth and database, then build admin managed-booking operations, provider approval, booking status history, and financial tracking.
